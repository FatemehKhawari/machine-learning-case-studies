# Machine Learning Case Studies

A collection of supervised machine learning case studies covering classification, regression, data preprocessing, feature engineering, and model evaluation.

## Case Study 1: Iris Flower Classification

### Dataset

The Iris dataset was collected by the British scientist **Ronald A. Fisher** in 1936 for a statistical study on flower classification. It is one of the most widely used datasets for demonstrating machine learning algorithms.

The dataset contains **150 samples** and **4 numerical features**:

* Sepal length
* Sepal width
* Petal length
* Petal width

The objective is to classify iris flowers into **three species (classes)**:

* Iris-setosa
* Iris-versicolor
* Iris-virginica

### Applications

The Iris dataset is commonly used for:

* Classification model development and evaluation
* Data visualization and exploratory data analysis (EDA)
* Feature selection
* Dimensionality reduction techniques such as PCA (Principal Component Analysis)
* Clustering experiments
* Comparing machine learning algorithms
