# Iris Flower Classification

## Objective

The goal of this project is to build and evaluate machine learning classification models to predict the species of iris flowers based on their physical measurements.

## Dataset

The Iris dataset was collected by the British scientist **Ronald A. Fisher** in 1936 for a statistical study of flower classification. It is one of the most widely used datasets for demonstrating machine learning algorithms.

The dataset contains:

- **150 samples**
- **4 numerical features**

Features:

- Sepal length
- Sepal width
- Petal length
- Petal width

The target variable contains **3 flower species**:

- Iris-setosa
- Iris-versicolor
- Iris-virginica

## Machine Learning Tasks

This project includes:

- Exploratory Data Analysis (EDA)
- Data visualization
- Feature analysis
- Train/test data splitting
- Model training
- Model evaluation

## Models

The following classification algorithms are implemented and compared:

- Logistic Regression
- Decision Tree
- Random Forest

## Evaluation Metrics

Models are evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- Classification Report

## Applications of the Iris Dataset

The Iris dataset is commonly used for:

- Classification experiments
- Machine learning algorithm comparison
- Data visualization
- Feature selection
- Dimensionality reduction techniques such as PCA
- Clustering experiments
